Part 01 · Number Functions

What is a number function?

Simple meaning: a number function takes a number in, does one job on it, and gives a number back.

1Input → Function → Output
INPUT
45.678
→
FUNCTION
ROUND(…, 2)
→
OUTPUT
45.68
Like a juice machine: fruit goes in, juice comes out. The machine is the function. 
SELECT ROUND(45.678, 2) FROM DUAL;
2The seven number functions · click one to jump
Number Function · ROUND

ROUND

Simple meaning: keep the digits you want, then look at the very next digit. If it is 5 or more, the last kept digit goes up by one. Otherwise it stays.

2Visual explanation · try it yourself
Try:
    ROUND(45.678, 2)=45.68
    5The SQL for your experiment
    
        
    
      
    
    
    
    
    
      
    
        
    3SQL syntax
    
        
    ROUND(number, decimal_places)
    
        
    decimal_places is optional (default 0). It can be negative: -1 rounds to tens, -2 to hundreds.
    
      
    
      
    
        
    4Example
    
        
    SELECT ROUND(45.678, 2)
FROM DUAL;
    
        
    ROUND(45.678,2)
    45.68
    
      
    
      
    
        
    Formal definition
    
        
        
    Oracle
    ROUND(n, integer) returns n rounded to integer places to the right of the decimal point. If integer is omitted, n is rounded to 0 places. A negative integer rounds digits to the left of the decimal point.
    Halfway values
    For NUMBER values, a 5 is rounded away from zero: ROUND(2.5) = 3 and ROUND(-2.5) = -3.
    
      
    
      
    
        
    6Quick check · predict
    
        
    SELECT ROUND(12.345, 1) FROM DUAL;
    
        
        
    12.3
    Keep 1 decimal (12.3), look at the next digit: 4. 4 < 5, so 3 stays.
    
      
    
    
    
  
    

    



    
  
    
    
    Number Function · TRUNC
    
    
    TRUNC
    
    
    Simple meaning: TRUNC is a pair of scissors. It keeps the digits you ask for and cuts off the rest. It never looks at the cut digits, so it never rounds.
    
  
    
  
    
    
    
      
    
        
    2Visual explanation · try it yourself
    
        
    
          
    
          
    
          
        
    
        
    Try:
          
          
          
          
          
        
    
        
    
        
    
        
      
        
      TRUNC(45.678, 2)=45.67
      
      
      
      
      
        
      5The SQL for your experiment
      
        
      
        
      
      
      
    
      
    
      
      
      
        
      3SQL syntax
      
        
      TRUNC(number, decimal_places)
      
        
      decimal_places is optional (default 0) and can be negative, just like ROUND.
      
      
      
      
      
        
      4Example
      
        
      SELECT TRUNC(45.678, 2)
FROM DUAL;
      
        
      TRUNC(45.678,2)
      45.67
      
      
      
      
      
        
      Formal definition
      
        
        
      Oracle
      TRUNC(n1, n2) returns n1 truncated to n2 decimal places. If n2 is omitted, n1 is truncated to 0 places. n2 can be negative to truncate (make zero) n2 digits left of the decimal point.
      Direction
      Truncation always moves toward zero: TRUNC(-7.9) = -7.
      
      
      
      
      
        
      6Quick check · predict
      
        
      SELECT TRUNC(99.99, 0) FROM DUAL;
      
        
        
      99
      TRUNC cuts both 9s after the point. It does not care that they are big.
      
      
      
    
      
  
      

      



      
  
      
    
      Compare
      
    
      ROUND vs TRUNC
      
    
      ROUND = look at the next digit and decide. TRUNC = cut the remaining digits. Same input, sometimes different answers.
      
  
      
  
      
    
      
      
      
      
      
      
    
      
    
      Try:
      
      
      
      
      
    
      
    
      
    
      
      
      
        
      ROUND
      
        
      Look at the next digit and decide.
      
        
      
        
      
        
      
        
      
      
      
      
      
        
      TRUNC
      
        
      Cut the remaining digits.
      
        
      
        
      
        
      
        
      
      
      
    
      
    
      
  
      
  
      
    
      6Quick check · predict both
      
    
      SELECT ROUND(5.55, 1), TRUNC(5.55, 1) FROM DUAL;
      
    
    
      5.6 and 5.5
      ROUND sees the last 5 (≥ 5) and bumps 5 → 6. TRUNC just cuts it off.
      
  
      

      



      
  
      
    
      Number Functions · CEIL & FLOOR
      
    
      CEIL and FLOOR
      
    
      Simple meaning: picture a room. CEIL takes the number up to the ceiling, the next whole number above it. FLOOR takes it down to the floor, the whole number below it.
      
  
      
  
      
    
      
      
      
        
      2Number line · try it yourself
      
        
      
          
      
          
        
      
        
      Try:
          
          
          
          
          
        
      
        
      
        
        
      
        
      
          
      
          
      
        
      
        
      Watch out with negatives! On the number line, "up" means toward the right (bigger). So CEIL(-4.3) = -4, not -5. FLOOR(-4.3) = -5.
      
      
      
    
      
    
      
      
      
        
      3SQL syntax
      
        
      CEIL(number)
FLOOR(number)
      
      
      
      
      
        
      4Example
      
        
      SELECT CEIL(4.3) FROM DUAL;
SELECT FLOOR(4.3) FROM DUAL;
      
        
      CEIL(4.3)FLOOR(4.3)
      54
      
      
      
      
      
        
      Formal definition
      
        
        
      CEIL(n)
      Returns the smallest integer greater than or equal to n.
      FLOOR(n)
      Returns the largest integer less than or equal to n.
      Integers
      If n is already a whole number, both return n itself: CEIL(7) = FLOOR(7) = 7.
      
      
      
      
      
        
      6Quick check · predict
      
        
      SELECT FLOOR(-0.5) FROM DUAL;
      
        
        
      -1
      -0.5 sits between -1 and 0. FLOOR goes down (left) to -1.
      
      
      
    
      
  
      

      



      
  
      
    
      Number Function · MOD
      
    
      MOD
      
    
      Simple meaning: share things out in equal groups. MOD tells you how many are left over.
      
  
      
  
      
    
      
      
      
        
      2Division, step by step · try it yourself
      
        
      
          
      
          
      
          
        
      
        
      Try:
          
          
          
          
          
          
        
      
        
      
        
      
        
        
        
        MOD(17, 5)=2
        
      
        
      
        
        
        5The SQL for your experiment
        
        
        
        
        
      
        
    
        
    
        
      
        
        
        3SQL syntax
        
        
        MOD(number, divisor)
        
      
        
      
        
        
        4Example
        
        
        SELECT MOD(17, 5)
FROM DUAL;
        
        
        MOD(17,5)
        2
        
      
        
      
        
        
        Real-world · predict
        
        
        32 students are divided into teams of 5. How many students are left without a team?
        
        
        
        MOD(32, 5) = 2
        5 × 6 = 30 students in 6 teams, 32 − 30 = 2 left over.
          
        
      
        
      
        
        
        Formal definition
        
        
        
        Oracle
        MOD(m, n) returns the remainder of m divided by n. It returns m if n is 0.
        Sign
        Oracle computes m - n * TRUNC(m / n), so the result has the same sign as m: MOD(-17, 5) = -2.
        
      
        
      
        
        
        6Quick check · predict
        
        
        SELECT MOD(10, 2) FROM DUAL;
        
        
        
        0
        Nothing is left over. That is how SQL checks for even numbers: MOD(n, 2) = 0.
        
      
        
    
        
  
        

        



        
  
        
    
        Number Function · ABS
        
    
        ABS
        
    
        Simple meaning: ABS returns the distance from zero. Distance is never negative, so the result is never negative.
        
  
        
  
        
    
        
      
        2Distance on the number line · try it yourself
        
      
        
        
        
        
      
        
      
        Try:

        ABS(number)
        
      
        
      
        
        
        4Examples
        
        
        SELECT ABS(-25), ABS(25), ABS(0)
FROM DUAL;
        
        
        ABS(-25)ABS(25)ABS(0)
        25250

        6Quick check · predict
        
        
        SELECT ABS(-0.75) FROM DUAL;
        
        
        
        0.75
        -0.75 is 0.75 steps away from zero.
        
      
        
    
        
  
        

        



        
  
        
    
        Number Function · SIGN
        
    
        SIGN
        
    
        Simple meaning: SIGN does not care how big a number is. It only says which side of zero it is on: -1, 0 or 1.
        
  
        
  
        
    
        
      
        2Three zones · try it yourself

        0

        1
        
      
        
      
        
      
        
      
        
    
        
    
        
      
        
        
        3SQL syntax
        
        
        SIGN(number)
        
      
        
      
        
        
        4Examples
        
        
        SELECT SIGN(-25), SIGN(0), SIGN(25)

        SIGN(-25)SIGN(0)SIGN(25)

        6Quick check · predict
        
        
        SELECT SIGN(-0.001) FROM DUAL;
        
        
        
        -1
        Tiny, but still on the negative side.

        Part 02 · Date Functions
        
    
        Dates are numbers too (sort of)
        
    
        Simple meaning: Oracle can calculate with dates just like it calculates with numbers. The unit is one day: add 1 and you get tomorrow.
        
  
        
  
        
    
        
      
        2Move the calendar page
        
      
        
        
        OCT
        07
        2026
        WEDNESDAY
        
        
        
          
        
            
            
            
            
            
          
        
          
        
          
        
        
        
      
        
      
        
        
        DATE + number
        → DATE
        
        
        DATE − number
        → DATE
        
        
        DATE − DATE
        → number of days
        
      
        
    
        
    
        
      
        
        
        3Writing a date in SQL
        
        
        DATE '2026-10-07'
        
        
        An ANSI date literal always uses YYYY-MM-DD. Oracle's DATE type also stores a time (hours, minutes, seconds). A literal like this has time 00:00:00.
        
        
        How a date is displayed depends on the NLS_DATE_FORMAT setting. Many tools show 07-OCT-26. This app shows 07-OCT-2026 so the year is clear.
        
      
        
      
        
        
        6Quick check · predict
        
        
        SELECT DATE '2026-10-07' - 7 FROM DUAL;
        
        
        
        30-SEP-2026
        Seven days back crosses into September. Oracle handles month lengths for you.
        
      
        
    
        
  
        

        



        
  
        
    
        Date Function · SYSDATE
        
    
        SYSDATE
        
    
        Simple meaning: SYSDATE is the clock on the wall of the database server room. It returns the current date and time of the database server's operating system.
        
  
        
  
        
    
        
      
        2Live · Database Server Date/Time
        
      
        
        
        
          
        
      
        
      
        
        
        DATABASE SERVER DATE/TIME · SYSDATE
        
        
        --:--:--
        
        
        --
        
        
        
      
        
      
        SELECT SYSDATE
FROM DUAL;
        
      
        
      
        No parentheses: write SYSDATE, not SYSDATE(). Every time you run the query you get a new value, because the clock keeps ticking.
        
    
        
    
        
      
        
        
        3SQL syntax
        
        
        SYSDATE
        
        
        Returns a DATE with a time part. Some tools show only the date part by default, but the time is still there.
        
      
        
      
        
        
        4Common uses
        
        
        -- a week from now
SELECT SYSDATE + 7 FROM DUAL;
-- this time yesterday
SELECT SYSDATE - 1 FROM DUAL;
        
      
        
      
        
        
        6Quick check · predict
        
        
        What does SELECT SYSDATE + 1 FROM DUAL; return?
        
        
        
        The same time tomorrow. +1 adds exactly one day (24 hours) to the server's current date and time.
        
      
        
    
        
  
        

        



        
  
        
    
        Date Function · CURRENT_DATE
        
    
        CURRENT_DATE
        
    
        Simple meaning: CURRENT_DATE is the watch on your wrist. It returns the current date and time in your session's time zone.
        
  
        
  
        
    
        2SYSDATE vs CURRENT_DATE · live
        
    
        
      
        
      
        
    
        
    
        
      
        SYSDATE · DATABASE SERVER
        --
        --
        
      
        CURRENT_DATE · YOUR SESSION
        --
        --
        
    
        
    
        
  
        
  
        
    
        
      
        3SQL syntax & example
        
      
        SELECT SYSDATE, CURRENT_DATE
FROM DUAL;
        
      
        
      
        SYSDATE → database server  ·  CURRENT_DATE → current session. If both use the same time zone, they show the same value.
        
    
        
    
        
      
        
        
        6Quick check · predict
        
        
        The server runs on UTC. Your session is in India (UTC+05:30). SYSDATE shows 10:00. What time does CURRENT_DATE show?
        
        
        
        15:30
        Same moment, read from your session's time zone: 10:00 + 5:30.
        
      
        
      
        
        
        Good to know
        
        
        
        A session's time zone can be changed with ALTER SESSION SET TIME_ZONE = 'Asia/Kolkata';. SYSDATE does not change, CURRENT_DATE does. Both return the DATE data type.
        
      
        
    
        
  
        

        



        
  
        
    
        Date Concept · Arithmetic
        
    
        Date arithmetic
        
    
        Simple meaning: adding a number to a date walks forward that many days. Subtracting walks backward. Subtracting two dates tells you how many days are between them.
        
  
        
  
        
    
        2Walk the timeline · Date ± Number → Date
        
    
        
      
        
      
        
      
        
      
    
        
    
        Try:
      
      
      
      
      
    
        
    
        
    
        
    
        =
        
    
        
    
        
  
        
  
        
    
        
      
        2Date − Date → Number of days
        
      
        
        
        
        
        
      
        
      
        
      
        
        −=
      
        
      
        
      
        
      
        Real use: "How many days until the exam?" If the dates have a time part, the answer can contain a fraction of a day (0.5 = 12 hours).
        
    
        
    
        
      
        
        
        3Rules
        
        
        date + number  -- DATE
date - number  -- DATE
date - date    -- days
        
        
        You cannot add two dates together. date + date gives an error.
        
      
        
      
        
        
        6Quick check · predict
        
        
        SELECT DATE '2026-03-01' - DATE '2026-02-01' FROM DUAL;
        
        
        
        28
        February 2026 has 28 days (2026 is not a leap year).
        
      
        
    
        
  
        

        



        
  
        
    
        Date Function · ADD_MONTHS
        
    
        ADD_MONTHS
        
    
        Simple meaning: jump forward or backward by whole months. Positive numbers move forward in time; negative numbers move backward.
        
  
        
  
        
    
        
      
        
        
        2Month timeline · try it yourself
        
        
        
          
        
          
        
          
        
        
        
        Try:
          
          
          
          
          
        
        
        
        
        
        
        
        =
        
        
        
        
        
        
        
      
        
    
        
    
        
      
        
        
        3SQL syntax
        
        
        ADD_MONTHS(date, months)
        
      
        
      
        
        
        4Example
        
        
        SELECT ADD_MONTHS(DATE '2026-01-15', 3)
FROM DUAL;
        
        
        ADD_MONTHS(DATE'2026-01-15',3)
        15-APR-2026
        
      
        
      
        
        
        Formal definition
        
        
        
        ADD_MONTHS(date, integer) returns date plus integer months. If date is the last day of its month, or the result month has fewer days than the day of date, the result is the last day of the result month. Otherwise the result has the same day of the month.
        
      
        
      
        
        
        6Quick check · predict
        
        
        SELECT ADD_MONTHS(DATE '2026-03-31', -1) FROM DUAL;
        
        
        
        28-FEB-2026
        There is no 31st February, so Oracle uses the last day of February.
        
      
        
    
        
  
        

        



        
  
        
    
        Date Function · MONTHS_BETWEEN
        
    
        MONTHS_BETWEEN
        
    
        Simple meaning: measure the gap between two dates in months. The answer can include a fraction, like 3.16 months.
        
  
        
  
        
    
        
      
        2Measure the gap · try it yourself
        
      
        
        
        
        
        
        
      
        
      
        Try:
        
        
        
        
        
      
        
      
        
      
        
      
          
      
          Result
          
      
          
      
          
    
          
    
          
      
          
        
          3SQL syntax
          
        
          MONTHS_BETWEEN(date1, date2)
          
        
          Positive if date1 is later. Negative if date1 is earlier. Order matters!
          
      
          
      
          
        
          4Example
          
        
          SELECT MONTHS_BETWEEN(
    DATE '2026-04-15',
    DATE '2026-01-15'
)
FROM DUAL;
          
        
          RESULT
          3
          
      
          
      
          
        
          Formal definition
          
        
        
          If both dates have the same day of the month, or both are the last day of their months, the result is a whole number. Otherwise Oracle adds a fraction based on a 31-day month (and also counts the time part). People often wrap it: ROUND(MONTHS_BETWEEN(d1, d2), 2).
          
      
          
      
          
        
          6Quick check · predict
          
        
          MONTHS_BETWEEN(DATE '2026-01-15', DATE '2026-04-15')
          
        
        
          -3
          Date 1 is earlier than date 2, so the answer is negative.
          
      
          
    
          
  
          

          



          
  
          
    
          Date Function · NEXT_DAY
          
    
          NEXT_DAY
          
    
          Simple meaning: "When is the next Monday after this date?" Oracle walks forward through the calendar and stops at the first matching weekday. It never returns the start date itself.
          
  
          
  
          
    
          
      
          2Calendar search · try it yourself

          NEXT_DAY(date, 'MONDAY')

          09-OCT-2026 is a Friday. NEXT_DAY(DATE '2026-10-09', 'FRIDAY') = ?
          
        
        
          16-OCT-2026
          NEXT_DAY always looks after the start date, so it skips to next week's Friday.

          Date Function · EXTRACT
          
    
          EXTRACT
          
    
          Simple meaning: take a date apart like a puzzle and pick one piece: the day, the month or the year. You get back a number.
          
  
          
  
          
    
          
      
          2Take the date apart · try it yourself

          Date Function · ROUND
          
    
          ROUND with dates
          
    
          Simple meaning: move the date to the nearest start of a unit (day, month or year). With numbers, ROUND looks at a digit. With dates, it checks which half of the unit the date is in.
          
  
          
  
          
    
          
      
          2Which half? · try it yourself
          
      
          
        
          
        
          
        
          
        
      
          
      
          Try:
        
        
        
        
        
      
          
      
          
      
          
      
          
      
            
      
            =
            
      
            
      
            
    
            
    
            
      
            
        
            3SQL syntax
            
        
            ROUND(date)
ROUND(date, 'MONTH')
ROUND(date, 'YEAR')
            
        
            No format → nearest day. 'MONTH' → nearest 1st of a month. 'YEAR' → nearest 1st January.
            
      
            
      
            
        
            Oracle's rules
            
        
        
            ROUND(date)
            Rounds to the nearest day: time at or after 12:00 noon rounds up to the next day.
            'MONTH'
            Rounds up on the 16th day: days 1–15 → 1st of this month; 16th onward → 1st of next month (for every month length).
            'YEAR'
            Rounds up on 1st July: Jan–Jun → 1 Jan this year; Jul–Dec → 1 Jan next year.
            
      
            
      
            
        
            6Quick check · predict
            
        
            ROUND(DATE '2026-10-15', 'MONTH')
            
        
        
            01-OCT-2026
            The 15th is still in the first half (rounding up starts on the 16th).
            
      
            
    
            
  
            

            



            
  
            
    
            Date Function · TRUNC
            
    
            TRUNC with dates
            
    
            Simple meaning: TRUNC moves the date back to the beginning of the unit. TRUNC(date) removes the time (back to midnight). TRUNC(date,'MONTH') goes back to the 1st.
            
  
            
  
            
    
            
      
            2Go back to the start · try it yourself
            
      
            
        
            
        
            
        
            
        
      
            
      
            Try:
        
        
        
        
      
            
      
            
      
            
      
            =
            
      
            
      
            
    
            
    
            
      
            
        
            3SQL syntax
            
        
            TRUNC(date)
TRUNC(date, 'MONTH')
TRUNC(date, 'YEAR')
            
        
            No format → same day at 00:00:00. 'MONTH' → 1st of the month. 'YEAR' → 1st January.
            
      
            
      
            
        
            4Example
            
        
            SELECT TRUNC(DATE '2026-10-18', 'MONTH')
FROM DUAL;
            
        
            RESULT
            01-OCT-2026
            
        
            Real use: WHERE TRUNC(order_date) = DATE '2026-10-07' finds every order on that day, whatever the time.
            
      
            
      
            
        
            6Quick check · predict
            
        
            TRUNC(DATE '2026-10-18', 'YEAR')
            
        
        
            01-JAN-2026
            Back to the start of the year. TRUNC never moves forward.
            
      
            
    
            
  
            

            



            
  
            
    
            Compare
            
    
            ROUND vs TRUNC with dates
            
    
            TRUNC always goes back to the start. ROUND goes back or forward, whichever start is nearer.

            6Quick check · predict both
            
    
            For DATE '2026-07-01' with 'YEAR': what do ROUND and TRUNC return?
            
    
    
            ROUND → 01-JAN-2027   TRUNC → 01-JAN-2026
            1st July is where ROUND starts rounding up. TRUNC still goes back.
